# SwiftLane – Cab Booking System

Full-stack college project using React (Vite), Node.js + Express, and MySQL 5.5-compatible SQL.

## Database
1. Start MySQL.
2. Open MySQL Command Line Client.
3. Run: `SOURCE C:/path/to/swiftlane/backend/sql/swiftlane.sql;`
4. If your MySQL root password is set, put it in `backend/.env`.

## Backend
```powershell
cd backend
copy .env.example .env
npm install
npm start
```
Runs on http://localhost:5000

## Frontend
Open another terminal:
```powershell
cd frontend
npm install
npm run dev
```
Normally opens at http://localhost:5173
